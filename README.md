# বিনিয়োগ খাতা 💰

কোথায় কত টাকা invest করছো — সব হিসাব এক জায়গায় রাখার মোবাইল-বান্ধব ওয়েব অ্যাপ।

## ফিচার
- নতুন এন্ট্রি যোগ / এডিট / ডিলিট (জায়গা, টাকার পরিমাণ, তারিখ, ক্যাটাগরি, নোট)
- মোট বিনিয়োগ, এই মাসের হিসাব, মোট এন্ট্রি — সামারি কার্ড
- খাতভিত্তিক (ক্যাটাগরি) চার্ট
- সার্চ
- CSV ডাউনলোড (ব্যাকআপ/এক্সেলের জন্য)
- সম্পূর্ণ বাংলায় UI, বাংলা সংখ্যা
- সব ডেটা ফোনের ব্রাউজারেই সংরক্ষিত থাকে (localStorage) — কোনো সার্ভার লাগে না

## ব্যবহার
`index.html` ফাইলটি ফোনের ব্রাউজারে খুললেই চলবে। হোম স্ক্রিনে যোগ করলে অ্যাপের মতো ব্যবহার করা যায়।

## ব্যাকআপ
CSV ডাউনলোড বোতাম চাপ দিলে সব হিসাবের ব্যাকআপ পাওয়া যায়।
